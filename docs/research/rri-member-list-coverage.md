# RRI displayed member-list coverage

Checked: **2026-08-13**

## Evidence boundary

This inventory transcribes every ministry-label row currently displayed on Royal Rangers International's member-nations page [R1]. It is a coverage worklist, not a claim that the page is a complete country register or that every displayed row has a verified National Program. RRI displays **75 rows in 5 groupings**: Africa 10, Asia Pacific 11, Eurasia 7, Europe 27, and Latin America/Caribbean 20. RRI's home page separately says the ministry operates in more than 90 nations [R2].

An ISO 3166-1 alpha-2 code is supplied only where the displayed row maps unambiguously to one assigned country or territory code. The combined `Bahamas, Turks & Caicos Islands` row is preserved as one ministry label and receives no single ISO code. `Transnistria` is also preserved as displayed and receives no ISO code because it has no separately assigned ISO 3166-1 code. Historical display names such as `Swaziland` and `Macedonia` are not silently rewritten; their unambiguous current country codes are shown alongside the source label.

The only official National Program names recorded below are the five supported by separately reviewed, first-party national sources in the initial-cohort research [R3]. Every other row remains `program not verified`; the RRI row alone establishes a displayed ministry/member label and grouping, not an official national ministry name, public directory, or current local unit.

## Reproducible update procedure

1. Fetch [R1] and transcribe its five displayed columns in order; do not split combined labels.
2. Compare each grouping and row count with the totals above. A changed page creates a review task; it does not silently alter canonical facts.
3. Assign one ISO code only for an unambiguous one-row-to-one-code mapping. Preserve the RRI label separately from current civil naming.
4. Add an official National Program name only after a current first-party national program or controlling ministry source states it.
5. Keep the status `program not verified` until that evidence is reviewed. RRI membership alone does not establish a public directory or local outpost.
6. Never infer program completeness, FCF state, local-unit identity, or publication readiness from this inventory.
