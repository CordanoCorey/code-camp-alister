# Link public event truth to private Outpost intent through a snapshot

Reference Calendar occurrences remain public organizer facts, while an Outpost's intent to attend is stored in a dedicated private Reference Event Plan linked to its group-owned calendar entry. The plan keeps only an allowlisted snapshot and requires explicit editor acceptance of material public changes; this costs a comparison step but prevents public maintenance from silently changing private operational intent or exposing which Outposts selected an event.
