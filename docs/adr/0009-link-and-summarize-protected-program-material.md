# Link and summarize protected program material until licensed

The Advancement Library and Handbook Listings publish verified metadata, original summaries, planning aids that do not store youth progress, and clearly identified official links, while full handbooks, worksheets, lessons, artwork, and exact protected text remain with their authorized publishers. Ranger Outpost Hub adds any verbatim or hosted material only after written permission specifies the content, countries, formats, translations, and required notices.
