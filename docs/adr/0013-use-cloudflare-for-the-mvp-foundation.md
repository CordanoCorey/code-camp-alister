# Use Cloudflare for the MVP foundation

The Ranger Outpost Hub MVP keeps the existing React and Vite frontend and uses Cloudflare Workers for server-only behavior, D1 for structured data and search, and Cloudflare Access to protect the sole Operator area. This provides a small managed foundation for a public read-only site with one editor while retaining scheduled-work and recovery capabilities without building the future multi-account platform now.
