# Separate ordinary authentication from Operator Access

Ranger Outpost Hub will use pinned Better Auth on the existing Cloudflare Worker and D1 for ordinary adult email/password identity, email verification, password recovery, and revocable sessions. Cloudflare Access and the fixed D1 Operator lifecycle remain a separate system for the sole Operator Account: an ordinary session is never an Access identity, an Operator session is never an ordinary customer session, and neither system can claim or authorize the other.

Better Auth owns credential verifiers, verification and recovery bearer material, durable rate limits, and sessions. Ranger Outpost Hub owns the transient adult-eligibility challenge, retained Adult Eligibility Record, Onboarding Path, private Display Name, Claimed Position, and Current Outpost or scoped unmatched claim. A Claimed Position and Current Outpost are private context only; they create no membership, Position Verification, Permission Grant, publishing authority, or Operator authority.

Public browsing remains anonymous. Production signup fails closed unless the Worker has a high-entropy auth secret, one canonical HTTPS origin and exact trusted origins, durable abuse controls, an explicitly configured transactional-email provider, and a verified sending identity. Local verification and recovery previews require an explicit loopback-only flag that production configuration rejects. Auth tokens, credentials, raw email, Birth Year, private profile data, IP address, and user agent are never placed in public projections, caches, analytics, or application logs. Youth accounts remain excluded.
